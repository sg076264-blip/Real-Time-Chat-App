# CHATZO Frontend Prototype

A desktop-first React + Vite UI prototype for CHATZO.

## Run locally

1. Extract this folder into your existing repository as `frontend`.
2. Open a terminal in `frontend`.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Included
- Three-column desktop chat layout (navigation rail, conversation list, chat)
- Searchable sample conversation list
- Selectable conversations
- Send-message interaction (local demo state only)
- Dark and light themes
- Conversation details panel
- Responsive narrow-screen layout

## Important
This is a frontend-only visual prototype. It currently uses sample data and does not connect to your Express API, MongoDB, or Socket.IO backend. Existing backend files are not included or modified.
