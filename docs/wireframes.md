# UI Wireframes — Real-Time Chat App

## 1. Login Screen
- App name and logo
- Email input
- Password input
- Login button
- Sign-up link

## 2. Dashboard / Room List
- User profile
- Search rooms
- Create room button
- Available rooms list
- Open room option

## 3. Main Chat Screen
- Room name
- Online members count
- Chat message history
- Sender name and timestamp
- Typing indicator
- Message input
- Send button

## 4. Room Details
- Room name
- Room description
- Members list
- Online status
- Leave room button
