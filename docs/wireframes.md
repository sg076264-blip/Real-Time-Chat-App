
# UI Wireframes — Real-Time Chat App

## 1. Login Screen

### Purpose
Allows existing users to log in and new users to create an account.

### Elements
- App name and logo
- Email input
- Password input
- Login button
- Sign-up link

### Wireframe

```text
+----------------------------------+
|             ChatSpace            |
|      Connect. Chat. Collaborate. |
|                                  |
|          Welcome Back            |
|                                  |
|  Email                           |
|  [________________________]      |
|                                  |
|  Password                        |
|  [________________________]      |
|                                  |
|           [ LOGIN ]              |
|                                  |
|   Don't have an account? Sign Up |
+----------------------------------+
```

## 3. Main Chat Screen

### Purpose
Allows room members to communicate through real-time messages.

### Elements
- Room name
- Online members count
- Chat message history
- Sender name and timestamp
- Typing indicator
- Message input
- Send button

### Wireframe

```text
+------------------------------------------+
| <   # General Discussion       Members   |
|     12 Members · 5 Online                |
+------------------------------------------+
|                  Today                   |
|                                          |
| Rahul · 10:30 AM                         |
| +--------------------------------------+ |
| | Hey everyone! Welcome to the room.   | |
| +--------------------------------------+ |
|                                          |
|                       You · 10:32 AM     |
|          +-----------------------------+ |
|          | Let's discuss our project.  | |
|          +-----------------------------+ |
|                                          |
| Rahul is typing...                      |
+------------------------------------------+
| [ Type a message................ ] [Send]|
+------------------------------------------+
```
