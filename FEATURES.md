# Real-Time Chat App

## Problem Statement
Students and teams often communicate through different platforms, making conversations difficult to organize. This application provides a centralized platform where users can communicate instantly through chat rooms.

## User Roles
1. User
   - Register and log in
   - Create chat rooms
   - Join existing rooms
   - Send and receive messages
   - View online users
   - Manage basic profile

2. Room Member
   - View room conversations
   - Participate in discussions
   - View room members

## MVP Features
1. User Signup
2. User Login
3. Create Chat Rooms
4. Join Chat Rooms
5. Real-Time Messaging
6. Message History
7. Online Users List
8. User Profiles
9. Available Room List
10. Logout

## Future Features
- Typing Indicators
- Read Receipts
- Private Messaging
- Image and File Sharing
- Message Editing and Deletion
- Push Notifications
- Dark Mode

## Technology Stack
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Real-Time Communication: Socket.IO
- Version Control: Git and GitHub

## Project Goal
Build a fully functional real-time chat application
where multiple users can communicate through rooms
without refreshing the page.
